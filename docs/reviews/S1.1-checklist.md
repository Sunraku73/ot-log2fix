## 1. Redaction (priorita' massima)
- [ ] **[B]** Tutti i canary `MUST` di `tests/fixtures/redaction_canaries.tsv` sono assenti dall'output di `redact()`; c'e' un test parametrico che usa il manifest.
- [ ] I canary `SHOULD` sono coperti oppure marcati `xfail` con motivazione.
- [ ] Copertura delle chiavi: `password|passwd|pwd|pass|secret|*_password|*_pwd|*_enc`, sia con `=` sia con `:`, con spazi/TAB/virgolette, case-insensitive.
- [ ] Segreti specifici OpenText: `OTCSTicket`, `OTDSTicket`, `LLCookie`, header `Authorization: Basic`.
- [ ] Multilinea: elementi XML, continuazione `.properties`, base64 spezzato, blocchi PEM `-----BEGIN ... -----END`.
- [ ] Encoding: percent-encoding, `\uXXXX` nel JSON, base64/hex sotto chiavi sensibili, zero-width/NFKC (normalizzare prima del match).
- [ ] Credenziali dentro URL (`scheme://user:pass@`) e nella prosa ("with password '...'"), non solo `key=value`.
- [ ] L'ordine dei pattern non lascia frammenti (un pattern non "consuma" il contesto che serve a un altro).
- [ ] Nessun ReDoS: niente quantificatori annidati; test su una riga da 1 MB con un tempo massimo.
- [ ] I placeholder (`[REDACTED:kind]`) non contengono parti del segreto (ne' lunghezza ne' prefisso).
- [ ] **[B]** Con un provider cloud la redaction non si puo' disattivare: `OTLF_REDACT=false` e' accettato solo con `base_url` loopback, altrimenti exit 1.

- [ ] La sentinella `NON HO ABBASTANZA CONTESTO` viene resa in modo visibile (non come errore).

## 5. Correttezza ed exit code
- [ ] Exit 0 ok; 1 per file mancante, vuoto, non UTF-8, directory o configurazione utente non valida; 2 per errori di provider/rete/timeout.
- [ ] Retry solo per 429/5xx con backoff limitato; nessun retry su 4xx; timeout esplicito.
- [ ] Limite sulla dimensione del file (o chunking via `max_chunk_chars`): niente caricamento illimitato in RAM o invio al provider.
- [ ] I path/messaggi d'eccezione stampati con rich non interpretano markup (`[...]` nel nome file).
- [ ] Default coerenti tra `config.py` e `.env.example` (`base_url`, `model`).
